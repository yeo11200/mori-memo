# MORI 0.2.0 · 설정 화면 및 백그라운드 빠른 메모

## 원인

2026-09-08에 실행 중이던 PID 15802의 시작 시간은 2026-09-07 18:00:19였다. 앱 번들을 새로 만들고 `open`해도 기존 단일 인스턴스가 활성화되어 이전 renderer가 계속 보였다. 새 asar에는 모델 select와 API 입력이 있었지만 실제 실행 프로세스를 교체하지 않았다. 이번에는 이전 앱을 정상 종료하고 종료를 확인한 다음 패키징한다. 패키징된 실행 파일을 대상으로 별도 UI 테스트도 수행한다.

## 변경

- 설정에 MORI 0.2.0 표시, 모델 select, 원격 OpenAI API 키 설정 버튼을 제공한다. API 키 입력은 원격 제공자 선택 시 표시한다.
- 기본 전역 `⌘⇧Space`로 별도 작은 빠른 메모 창을 연다. `⌘Enter` 또는 저장 버튼으로 미분류에 저장하고 창을 숨긴다.
- Escape/닫기는 초안을 유지한 채 숨긴다. 초안은 프로세스 메모리에만 있으므로 완전 종료 전에는 저장해야 한다.
- 메인 창 닫기는 자동 저장 후 숨김 처리한다. 메뉴 막대 M에서 앱·빠른 메모·설정·완전 종료를 선택한다.
- 로그인 시 자동 실행은 설정에서 선택하고 저장한다. 설치만으로 종료된 프로세스가 단축키를 받을 수는 없으며, 창을 닫은 백그라운드 상태 또는 자동 실행 상태에서 작동한다.
- 기존 사용자 지정/해제 조합은 유지한다. 이전 기본 빠른 메모 `⌘⇧N`만 `⌘⇧Space`로 마이그레이션한다.
- 한 전역 단축키 등록이 실패해도 시작 시 나머지 단축키를 등록한다. 설정 저장은 기존대로 충돌 시 거부하고 이전 설정을 복구한다.
- 빠른 메모 IPC는 해당 창·프레임·URL만 허용하고 본문 크기와 중복 저장을 검증한다. 메인 편집 중인 본문을 덮어쓰지 않고 목록만 갱신한다.

## 검증

- 수정 전 quick-note smoke는 이전 기본 `⌘⇧N` 때문에 실패해 요구사항 누락을 재현했다.
- `npm test`: 40개 통과. `npm run build` 통과.
- `node scripts/smoke.mjs`: 기존 검색·AI·폴더·Markdown·휴지통 회귀 통과.
- `node scripts/quick-note-smoke.mjs`: 모델 select·API 입력·전역 등록·메인 창 숨김·빠른 메모 포커스·Escape 초안 유지·⌘Enter 한 번 저장·메인 목록 갱신 통과.
- 실제 OS 키 입력 자동화는 macOS에서 osascript 키스트로크 권한을 거부해 실행하지 못했다. 전역 등록 여부와 등록 콜백과 동일한 명령 경로를 테스트했다. 이 권한은 테스트 자동화에 관한 것으로 사용자 키보드 입력 권한과 다르다.

## 배포 확인

`node scripts/quick-note-smoke.mjs --packaged`로 새 앱 번들의 설정 및 빠른 메모를 확인한 뒤 실제 보관함으로 실행한다. 개발용 환경 변수 `WIKI_DEV_URL`은 패키징된 앱에서 무시한다.

패키징된 앱 테스트도 통과했다. 설정 select/API 키 입력과 빠른 메모 저장을 `release/mac-arm64/MORI.app/Contents/MacOS/MORI`로 직접 실행해 확인했다. 기존 사용자 설정의 빠른 메모 값은 이전 기본 `CommandOrControl+Shift+N`이므로 새 기본값으로 마이그레이션된다.
