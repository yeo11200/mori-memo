## 활용 방법

- 관심 있는 글은 별도 메모에 핵심 내용, 적용할 점, 원문 URL을 정리한다.
- 정리한 메모끼리는 `[[문서 제목]]`으로 연결한다. 외부 URL 자체는 MORI 그래프의 문서 연결선이 되지 않는다.

## 정리 메모

- 사용자가 제공한 링크 35개를 기준으로 정리했다. 현재 접속 가능 여부와 이전 주소는 별도로 검증하지 않았다.
- 마지막 MS 주소 뒤의 ‘카카오테크’는 이어 붙은 텍스트로 보고 분리했다. 카카오 링크는 국내 항목에 포함했다.
