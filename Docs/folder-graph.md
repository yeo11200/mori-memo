# 폴더 중심 지식 그래프 · MORI 0.2.1

## 구현

- 기본 진입 화면은 폴더 그래프다. 영속화된 빈 폴더와 기존 문서 폴더를 모두 포함한다.
- 노드에 폴더 이름·메모 수를 표시한다. 색상은 현재 폴더 목록 순서에 따라 구분하며 6개를 넘으면 재사용한다.
- 폴더 간 선의 숫자는 방향을 합산한 문서 참조 개수다. 같은 문서의 동일 대상을 향한 반복 링크는 한 번만 센다. 반대 방향 참조는 별도 링크다.
- 폴더를 선택하면 내부 문서 노드와 실제 위키 링크를 화살표로 표시한다. 외부 폴더 연결은 별도 목록에서 원문·대상 폴더를 함께 표시한다.
- 문서 선택 시 들어오는 링크, 나가는 링크, 찾을 수 없는 대상을 표시한다. 문서 제목이 중복되어 모호한 링크도 미해결로 표시한다.
- 문서 열기는 기존 ID로 이동한다. 그래프 탐색 자체는 문서와 AI를 변경하거나 실행하지 않는다.
- 폴더·문서 이름 검색, 75~200% 배율, 넓은 확대 화면, Escape 닫기와 키보드 포커스 이동을 지원한다.
- 최초 12개를 표시하고 더 보기로 추가한다. 일부만 표시된 지도에 없는 연결은 상세 링크 목록에서 확인할 수 있다.

## 검증

- 단위 테스트: 빈 폴더, 허위 연결 방지, 반복 링크 중복 제거, 폴더 간 집계, 이름 변경 alias, 모호한 이름·미해결 링크.
- 실제 Electron 임시 보관함: 폴더 선택, 링크 수, 들어오는/나가는/미해결 링크, 메모 열기, 이름 검색, 빈 폴더, 배율, 확대·Escape 포커스 복귀, 12개 이상 더 보기.
- 전체 테스트 43개와 TypeScript/Vite/Electron 빌드 통과. 사용자 보관함을 테스트에 사용하지 않았다.
- `npm run package:mac`와 `node scripts/graph-smoke.mjs --packaged`도 통과해 실제 0.2.1 앱 번들에서 화면과 탐색을 확인했다.

## 후속 후보

중첩 폴더 트리, 노드 드래그와 물리 배치, 태그 필터, 개별 폴더 색상 저장, 대규모 보관함 인덱스는 후속 범위다. 현재 폴더는 기존 폴더 문자열 단위로 묶는다.
