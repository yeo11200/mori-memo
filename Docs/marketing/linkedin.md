## 첫 소개 — 게시 본문

오늘 할 일을 정리하려고 여러 업무 도구를 다시 열어야 한다는 점이 불편했습니다.

일정은 Google Calendar에 있고, 담당 업무는 Jira에 있고, 회의 중 생각은 메모에 남습니다. 각 도구는 제 역할을 하지만, 오늘의 업무 맥락은 제가 다시 모아야 했습니다.

그래서 Mac용 로컬 메모 앱 MORI를 만들고, 0.8.0 무료 베타로 공개합니다.

서비스를 연결하고 자동 갱신을 설정하면 ‘오늘 데일리’를 만들거나 열 때 일정과 내 Jira 업무를 가져옵니다. 같은 날짜에는 같은 노트를 사용하고, 가져온 구역 밖에 회의 내용이나 개인 기록을 더할 수 있습니다.

설계하면서 세 가지를 중요하게 생각했습니다.

• 메모는 로컬 Markdown으로 보관하기
• 외부 업무를 다시 가져와도 개인 체크와 기록 지키기
• MORI의 체크를 Jira 원본 상태 변경과 구분하기

회의록에서 결정한 이유를 다른 문서와 연결할 수 있도록 메모 링크와 지식 그래프도 넣었습니다. 데일리가 하루의 체크리스트로 끝나지 않고, 나중에 다시 찾아볼 기록이 되었으면 합니다.

현재 제 사용 환경에서 Google Calendar와 Jira 연결을 확인했습니다. GitHub·GitLab 담당 이슈 기능도 구현했지만, 실계정 검증은 더 필요합니다.

Apple Silicon Mac용이며 Developer ID 서명·공증 전 베타입니다. Google 연결에는 최초 OAuth JSON 설정이 필요합니다. 완성된 서비스라고 소개하기보다 실제 업무에 맞는 흐름인지 피드백을 받으며 다듬으려 합니다.

## 운영 메모

첫 화면은 서비스 네 개의 로고보다 실제 데일리 화면으로 보여준다. 글의 ‘제 사용 환경에서 확인’은 작성자가 대화에서 보고한 동작 확인에 근거하며 다양한 사용자·조직 검증을 의미하지 않는다.

댓글의 질문을 업무 상황별로 기록한다. 채용 홍보·투자 모집·팀용 서비스라는 인상을 추가하지 않는다. 회사의 승인이나 공식 제품처럼 쓰지 않는다.

후속 글은 실제 피드백이나 수정이 생긴 뒤 ‘어떤 상황에서 막혔고 무엇을 바꿨는지’ 작성한다. 수치나 사례가 없으면 성과 글을 만들지 않는다.
