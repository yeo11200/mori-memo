# 2026-09-09 개발 계획 · MORI 0.3.0

어제 합의한 우선순위 1~3을 구현한다. AI 추천과 수집함은 후속 범위다.

## 이번 작업

1. 메모 중심 그래프: 점은 메모, 색상과 배경 영역은 폴더, 실선은 실제 위키 링크. 선택한 메모와 직접 연결된 메모를 강조하며 연결된 메모만 보기·폴더 필터를 제공한다. 기존 그래프는 폴더 요약으로 유지한다.
2. 연결 추가: 편집 중인 메모와 그래프 미리보기에서 대상 검색 → 문서 선택 → 선택적 이유 입력 → 저장. 기존 본문 끝에 ID 기반 위키 링크와 이유를 추가한다. 중복·자기 연결·삭제된 대상·저장 충돌을 거부한다.
3. 미리보기 카드: 제목·폴더·본문 일부·수정 날짜·들어오는/나가는 링크를 표시하고 열기와 연결 추가를 제공한다.

## 검증 기준

- 같은 폴더에 있다는 이유로 가짜 링크를 만들지 않는다.
- 동명 문서를 ID로 구분하고, 기존 본문·미저장 편집·버전 기록을 보존한다.
- 취소·실패 시 기존 본문을 덮어쓰지 않는다. 그래프 탐색은 AI를 호출하지 않는다.
- 임시 보관함 단위/앱 테스트 후 앱 번들을 검증한다. 이전 앱 프로세스를 정상 종료하고 새 앱을 실행한다.

## 후속 아이디어

- 버튼으로 AI 연결 후보와 근거를 제안하고 사용자가 선택한 연결만 적용.
- 빠른 메모 수집함에서 폴더·제목·연결을 한 화면에서 정리.

## 구현 선택

폴더 영역별 고정 배치를 사용한다. 물리 시뮬레이션과 드래그는 이번 범위에 포함하지 않는다. 연결 이유는 별도 DB를 만들지 않고 Markdown 본문에 함께 저장한다.

## 완료 및 검증

- 우선순위 1~3 구현 완료. MORI 0.3.0 macOS arm64 앱 패키징 완료.
- `npm test`: 8개 파일, 48개 테스트 통과. `npm run package:mac`: 타입 검사·번들·앱 패키징 통과.
- `node scripts/connections-smoke.mjs --packaged`: 폴더 영역, 실제 메모 링크, 미리보기, 검색·이유 입력, 연결 범위 필터, 미저장 본문 보존, 중복 후보 제외, 재로드 저장 확인 통과.
- `node scripts/graph-smoke.mjs --packaged`: 폴더 집계, 빈 폴더, 들어오는/나가는/미해결 링크, 문서 열기, 검색, 확대·축소, Escape 포커스, 더 보기 통과.
- 테스트는 임시 보관함을 사용했다. AI 추천과 수집함은 아직 후속 작업이며 이번 검증에서 AI를 호출하지 않았다.
- Git 제외 규칙 때문에 누락되었던 `electron/vault/vault.ts` 저장 기능 소스를 포함하도록 수정했다. 사용자 보관함과 비밀키는 계속 제외한다.
