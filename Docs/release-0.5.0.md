# MORI 0.5.0 — 메모 연결 개선

## 배포 범위

- 오른쪽 패널의 중복 AI 카드 제거. AI 작성·정리는 본문 도구 모음에서 실행한다.
- 실제 나가는 연결 수와 연결 추가 동작을 표시한다.
- 공통 키워드 기반 추천에 연결 버튼을 제공한다. 누르면 연결 창에서 대상이 미리 선택된다. 이유를 입력하고 저장한 경우에만 본문에 링크를 추가한다.
- 이미 현재 메모에서 연결했거나 현재 메모를 참조하는 메모는 추천에서 제외한다.
- 사용 가이드에서 기록, 검색, 메모 연결, 그래프, AI와 스킬 설치의 역할을 안내한다.
- 기존 아이콘 이름 표시와 스킬 설치 피드백 개선을 함께 포함한다.

## 배포 형태

Apple Silicon용 DMG. MORI.app 안에 mori-context 스킬을 포함하며 설정에서 설치한다. Codex·Claude 실행 프로그램 자체는 포함하지 않는다. 별도 설치와 로그인이 필요하다. 최초 설치에는 백업이 생기지 않으며 기존 스킬 교체 시 백업한다.

서명·공증 없는 무료 배포 방식은 유지한다. 앱 파일과 DMG 생성은 공개 업로드와 별개다.

## 검증

`npm test`, `node scripts/release-050-smoke.mjs --packaged`, `node scripts/skill-install-smoke.mjs`로 검증한다. 앱 테스트는 임시 보관함을 사용한다. 스킬 설치 테스트는 임시 홈 경로에 설치하여 개인 스킬을 변경하지 않는다.
