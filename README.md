## 실행

**Apple 메모 연동:** 상단 **Apple 메모 연동** 또는 첫 메모 화면의 **Apple 메모 가져오기** → **목록 읽기** → 폴더/개별 메모 선택 → **가져오기**. 이후 **연동한 모든 항목**으로 새 메모와 변경을 반영합니다. Apple 원본은 읽기만 하며, MORI와 원본이 함께 수정된 경우 비교 후 선택합니다. 현재 본문은 일반 텍스트로 가져오고 사진·PDF·표·체크 상태는 보존하지 않습니다.

```sh
npm install
npm run dev
```

## 확인

```sh
npm run test
npm run build
node scripts/smoke.mjs
node scripts/startup-smoke.mjs
node scripts/quick-note-smoke.mjs
node scripts/graph-smoke.mjs
npm run package:mac
```

`release/mac-arm64/MORI.app`에 Apple Silicon용 로컬 앱이 생성됩니다. `npm run package:dmg`는 무료 공개 베타용 Apple Silicon DMG를 만듭니다. 현재 빌드는 Developer ID 서명·공증 전 단계이며 배포 채널과 설치 안내는 [배포 계획](Docs/deployment-plan.md)을 따릅니다.

**MORI 0.2.0:** 기본 **⌘⇧Space**로 백그라운드 빠른 메모 창을 열고 **⌘Enter**로 미분류에 저장합니다. 앱 창을 닫아도 메뉴 막대 M에서 대기합니다. 완전 종료 시 전역 단축키도 종료되며, 설정의 **로그인 시 MORI 자동 실행**을 켜면 다음 로그인부터 자동으로 실행됩니다. Escape로 숨긴 빠른 메모 초안은 앱을 완전히 종료하기 전에 저장하세요.

## 기능

**0.3.0 메모 연결 그래프:** 기본 화면의 점은 메모, 색 영역은 폴더, 화살표는 실제 문서 참조입니다. 메모를 선택하면 본문 미리보기·수정 날짜·들어오는/나가는 링크가 표시됩니다. 폴더 필터와 **연결된 메모만**으로 탐색 범위를 좁힐 수 있습니다. **폴더 요약**으로 전환하면 기존 집계 화면을 볼 수 있습니다.

**폴더 요약:** 왼쪽 **그래프**에서 폴더별 메모 수와 폴더 간 링크 수를 확인합니다. 폴더 → 메모 순서로 선택하면 들어오는 링크·나가는 링크·미해결 링크가 표시됩니다. **확대** 버튼으로 넓게 보고, **이 메모 열기**로 편집합니다. 같은 폴더에 속한다는 이유로 연결선을 만들지 않습니다.

- Markdown 원문 저장, 자동 저장, 버전 충돌 감지, 휴지통·복구, 내보내기
- 폴더 생성·이름 변경·삭제·이동, 폴더별 필터와 메모 수
- `[[폴더/문서]]` 자동완성, 내부 링크, 백링크, 관련 메모, 문서 그래프
- 요청할 때 실행하는 Codex CLI·Claude CLI·OpenAI API 요약/풀어쓰기/회의록/연결 찾기
- 요약 결과 미리보기, 복사, 원문 아래 추가
- 캡처 삽입, 빠른 메모, 사용자 지정 단축키와 AI 명령

설정에서 로컬 기반 Codex/Claude CLI 또는 원격 OpenAI API를 선택합니다. CLI는 로그인된 실행 파일을 사용합니다. OpenAI API 키는 macOS safeStorage로 암호화해 보관함 밖에 저장합니다. API 기본 모델은 `gpt-5-nano`이며 모델은 선택 목록으로 지정합니다.

Codex의 기본 모델은 요청한 Luna 계열의 `gpt-5.6-luna`입니다. 맥에 설치된 `codex exec`를 로컬에서 호출하는 방식입니다. 앱에 별도 API 키나 Ollama를 입력하지 않으며, 모델 추론은 Codex 서비스에서 수행됩니다. 완전 오프라인 Ollama는 별도 확장 후보입니다. 본문 아래에 AI 결과를 추가하면 저장 성공 후 팝업이 닫히고 편집기로 돌아갑니다.

휴지통은 제목과 내용 미리보기를 표시합니다. 각 카드에서 복원하거나 **영구 삭제 → 영구 삭제 확인**으로 본문·버전 기록·저장된 AI 결과를 삭제할 수 있습니다. 첨부 파일과 이미 내보낸 외부 백업은 유지합니다.

왼쪽 검색창에서 제목·내용을 검색합니다. 기본 ⌘K로 검색창에 이동하며 기존 검색어가 선택됩니다. AI 창에서도 검색으로 이동할 수 있습니다. Enter로 첫 검색 결과를 열고 편집하며, Escape로 검색을 지우고 본문으로 돌아갑니다.

**AI로 작성·정리 → AI에게 작성 요청 → 초안 작성**으로 본문 없이도 문서를 생성합니다. 빈 메모에는 결과가 자동으로 입력됩니다. 기존 본문이 있거나 생성 중 내용을 수정했다면 결과 미리보기만 제공하며 원문을 유지합니다. AI 창을 검색 단축키로 닫아도 진행 중인 생성은 계속됩니다. 창의 닫기 버튼은 작업을 취소합니다.

메모 위의 **요약하기**는 버튼을 누를 때만 실행하고, **AI로 작성·정리**의 풀어 쓰기·회의록 정리는 기존 본문을 사용합니다.

설정의 단축키 입력칸에서 원하는 조합을 누르고 **설정 저장**을 누릅니다. Delete로 전역 단축키를 해제합니다. 다른 앱과 충돌하면 오류를 표시하며 기존 설정을 유지합니다. 캡처·빠른 메모 전역 단축키는 앱이 실행 중일 때 동작합니다.

화면 회귀 검증은 별도 임시 보관함과 테스트용 CLI를 사용합니다. OpenAI 통신은 모의 응답으로 테스트하며 실제 API 호출에는 사용자 키가 필요합니다. 화면 캡처에는 macOS 화면 기록 권한이 필요합니다.

기본 **⌘⇧P** 또는 왼쪽 **명령 팔레트**에서 새 메모·캡처·설정 같은 동작과 사용자 AI 명령을 실행합니다. 팔레트에는 문서 목록이 나오지 않습니다. 문서는 **⌘K 검색창**, 사이드바, 그래프에서 찾습니다. 설정의 **사용자 AI 동작**에 저장한 요청도 팔레트와 단축키에서 실행합니다. 단축키는 동작·키 조합·앱/전역 범위를 변경할 수 있고, Escape로 녹화를 취소합니다.

폴더 삭제는 문서를 **미분류**로 이동합니다. 기존 폴더와 중첩 경로 문자열은 보존하며 새 폴더 생성은 한 단계로 제공합니다. 폴더·제목 변경 전 링크는 alias로 유지합니다.

## 메모끼리 연결하는 방법

편집기 또는 그래프의 미리보기 카드에서 **연결 추가** → 제목·폴더·내용 검색 → 대상 선택 → 연결 이유(선택) → **연결 추가**를 누릅니다. 기존 본문 끝에 문서 ID 기반 위키 링크와 이유를 저장하므로 동명 메모도 구분합니다. 이미 연결된 메모와 자기 자신은 후보에서 제외됩니다. 아래처럼 직접 입력할 수도 있습니다.

1. 연결할 메모를 먼저 만듭니다. 예를 들어 `업무` 폴더에 `프로젝트 계획` 메모를 만듭니다.
2. 다른 메모를 열고 **편집하기**에서 본문에 `[[`를 입력합니다.
3. 자동완성에 나온 문서를 클릭하거나 **↑↓ → Enter**로 선택합니다. 폴더 경로가 함께 표시됩니다.
4. 자동 저장 후 **미리보기**에서 링크를 누르면 연결한 메모로 이동합니다.

직접 입력할 때는 다음 형식을 사용합니다.

```md
이번 회의의 기준은 [[프로젝트 계획]]입니다.
폴더를 지정하려면 [[업무/프로젝트 계획]]을 참고하세요.
화면에 짧게 표시하려면 [[업무/프로젝트 계획|계획 보기]]처럼 씁니다.
```

| 형식 | 동작 |
|---|---|
| `[[문서 제목]]` | 같은 이름이 하나인 문서를 연결 |
| `[[폴더/문서 제목]]` | 폴더까지 지정해 문서를 연결 |
| `[[폴더/문서 제목\|표시할 이름]]` | 연결 대상과 화면에 표시할 글자를 따로 지정 |

**회의 메모 → 프로젝트 계획** 링크를 넣으면, 프로젝트 계획의 **백링크**에 회의 메모가 나타납니다. 계획 메모에 반대 방향 링크를 다시 입력할 필요는 없습니다. 그래프의 **들어오는 링크**와 **나가는 링크**에서도 이 관계를 확인할 수 있습니다.

같은 폴더에 넣거나 본문에 제목만 적는 것으로는 연결되지 않습니다. 반드시 `[[...]]`를 사용합니다. 서로 다른 폴더의 문서를 연결하면 폴더 그래프에도 두 폴더 사이 선이 생깁니다.

대상 문서가 없으면 링크만으로 새 문서를 만들지 않습니다. 같은 이름의 문서가 여러 개이면 폴더 경로를 쓰거나 자동완성으로 대상을 선택하세요. 자동완성은 경로가 모호할 때 문서 ID로 연결합니다. 제목·폴더 변경 시 이전 이름은 alias로 남지만, 이후 다른 문서와 이름이 겹치면 다시 대상을 선택해야 할 수 있습니다. 코드 블록과 인라인 코드 안의 `[[...]]`는 실제 연결로 집계하지 않습니다.
