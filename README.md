## 실행

```sh
npm install
npm run dev
```

## 확인

```sh
npm run test
npm run build
node scripts/smoke.mjs
node scripts/startup-smoke.mjs
node scripts/quick-note-smoke.mjs
npm run package:mac
```

`release/mac-arm64/MORI.app`에 Apple Silicon용 로컬 앱이 생성됩니다. 현재 앱은 Developer ID 서명·공증 전 단계입니다.

**MORI 0.2.0:** 기본 **⌘⇧Space**로 백그라운드 빠른 메모 창을 열고 **⌘Enter**로 미분류에 저장합니다. 앱 창을 닫아도 메뉴 막대 M에서 대기합니다. 완전 종료 시 전역 단축키도 종료되며, 설정의 **로그인 시 MORI 자동 실행**을 켜면 다음 로그인부터 자동으로 실행됩니다. Escape로 숨긴 빠른 메모 초안은 앱을 완전히 종료하기 전에 저장하세요.

## 기능

- Markdown 원문 저장, 자동 저장, 버전 충돌 감지, 휴지통·복구, 내보내기
- 폴더 생성·이름 변경·삭제·이동, 폴더별 필터와 메모 수
- `[[폴더/문서]]` 자동완성, 내부 링크, 백링크, 관련 메모, 문서 그래프
- 요청할 때 실행하는 Codex CLI·Claude CLI·OpenAI API 요약/풀어쓰기/회의록/연결 찾기
- 요약 결과 미리보기, 복사, 원문 아래 추가
- 캡처 삽입, 빠른 메모, 사용자 지정 단축키와 AI 명령

설정에서 로컬 기반 Codex/Claude CLI 또는 원격 OpenAI API를 선택합니다. CLI는 로그인된 실행 파일을 사용합니다. OpenAI API 키는 macOS safeStorage로 암호화해 보관함 밖에 저장합니다. API 기본 모델은 `gpt-5-nano`이며 모델은 선택 목록으로 지정합니다.

Codex의 기본 모델은 요청한 Luna 계열의 `gpt-5.6-luna`입니다. 맥에 설치된 `codex exec`를 로컬에서 호출하는 방식입니다. 앱에 별도 API 키나 Ollama를 입력하지 않으며, 모델 추론은 Codex 서비스에서 수행됩니다. 완전 오프라인 Ollama는 별도 확장 후보입니다. 본문 아래에 AI 결과를 추가하면 저장 성공 후 팝업이 닫히고 편집기로 돌아갑니다.

휴지통은 제목과 내용 미리보기를 표시합니다. 각 카드에서 복원하거나 **영구 삭제 → 영구 삭제 확인**으로 본문·버전 기록·저장된 AI 결과를 삭제할 수 있습니다. 첨부 파일과 이미 내보낸 외부 백업은 유지합니다.

왼쪽 검색창에서 제목·내용을 검색합니다. 기본 ⌘K로 검색창에 이동하며 기존 검색어가 선택됩니다. AI 창에서도 검색으로 이동할 수 있습니다. Enter로 첫 검색 결과를 열고 편집하며, Escape로 검색을 지우고 본문으로 돌아갑니다.

**AI로 작성·정리 → AI에게 작성 요청 → 초안 작성**으로 본문 없이도 문서를 생성합니다. 빈 메모에는 결과가 자동으로 입력됩니다. 기존 본문이 있거나 생성 중 내용을 수정했다면 결과 미리보기만 제공하며 원문을 유지합니다. AI 창을 검색 단축키로 닫아도 진행 중인 생성은 계속됩니다. 창의 닫기 버튼은 작업을 취소합니다.

메모 위의 **요약하기**는 버튼을 누를 때만 실행하고, **AI로 작성·정리**의 풀어 쓰기·회의록 정리는 기존 본문을 사용합니다.

설정의 단축키 입력칸에서 원하는 조합을 누르고 **설정 저장**을 누릅니다. Delete로 전역 단축키를 해제합니다. 다른 앱과 충돌하면 오류를 표시하며 기존 설정을 유지합니다. 캡처·빠른 메모 전역 단축키는 앱이 실행 중일 때 동작합니다.

화면 회귀 검증은 별도 임시 보관함과 테스트용 CLI를 사용합니다. OpenAI 통신은 모의 응답으로 테스트하며 실제 API 호출에는 사용자 키가 필요합니다. 화면 캡처에는 macOS 화면 기록 권한이 필요합니다.

기본 **⌘⇧P** 또는 왼쪽 **명령 팔레트**에서 메모를 찾고 동작을 실행합니다. 설정의 **사용자 AI 동작**에 저장한 요청도 팔레트와 단축키에서 실행합니다. 단축키는 동작·키 조합·앱/전역 범위를 변경할 수 있고, Escape로 녹화를 취소합니다.

폴더 삭제는 문서를 **미분류**로 이동합니다. 기존 폴더와 중첩 경로 문자열은 보존하며 새 폴더 생성은 한 단계로 제공합니다. 폴더·제목 변경 전 링크는 alias로 유지합니다.
